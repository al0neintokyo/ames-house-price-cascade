# Оценка стоимости дома в Эймсе

Streamlit-приложение прогнозирует цену продажи дома по семи характеристикам. Это публикация приложения, разработанного в практической работе 11. Автор: Плющик Вячеслав.

## Как пользоваться

Измените числа в форме кликом по полю или кнопками `−` и `+`. Площади вводятся в квадратных футах. Выберите район из списка и нажмите **«Рассчитать цену»**. Приложение покажет базовую оценку, выбранную ветвь каскада и итог в долларах США.

Сначала общая модель Gradient Boosting даёт базовую цену. По значению OverallQual каскад либо усредняет её с прогнозом Ridge своей группы (1–5 и 6–7), либо использует прогноз отдельной модели Gradient Boosting (8–10). Приложение загружает обученные модели из `artifacts/` и ничего не переобучает. Подробнее о разбиении, выборе маршрутов и метриках: [MODEL.md](MODEL.md).

## Локальный запуск

Из корня проекта с Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows PowerShell вместо `source` используйте `.venv\Scripts\Activate.ps1`. Откройте адрес из вывода Streamlit (обычно http://localhost:8501).

## Streamlit Community Cloud

При создании приложения выбрать этот репозиторий, ветку `main`, файл `app.py` и Python 3.12 в Advanced settings. Зависимости находятся в `requirements.txt`. Секреты и переменные окружения не нужны. В `artifacts/models.joblib` содержится модель, которую я обучил для этой работы. Приложение не принимает сторонние файлы моделей.

## Данные и ограничения

Источник: [Kaggle House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data). Исходный CSV не включён: для прогноза нужны только файлы проекта. Модель обучена на исторических данных одного города. Не стоит использовать её как актуальную рыночную оценку дома.
